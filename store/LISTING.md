# Chrome Web Store listing

## Name

NAS Download Manager for Synology

## Summary

Add and manage Synology Download Station tasks from your browser.

## Category

Productivity

## Language

English

## Detailed description

Send downloads to your Synology NAS without switching away from the page you are browsing.

NAS Download Manager for Synology connects your browser to Download Station so you can add links, torrent files, and magnet links, choose a destination folder, and keep an eye on the queue from the toolbar.

Features:

- Add supported links and media from the right-click menu
- Paste URLs and magnet links or select a local torrent file
- Choose the destination folder for each new task
- View, sort, and filter Download Station tasks
- Pause, resume, remove, and clear tasks
- See active-download progress on the toolbar badge
- Receive completion notifications
- Use light, dark, or system theme

Requirements:

- A Synology NAS with Download Station installed and configured
- Network access from the browser to the NAS
- A valid NAS account with permission to use Download Station

Using HTTPS for the NAS connection is strongly recommended. An HTTP connection exposes credentials and session traffic to the local network and should not be used for a published build unless it satisfies the store's current user-data requirements.

NAS Download Manager for Synology is a fork of the open-source extension "NAS Download Manager (for Synology)", with updated browser support and ongoing maintenance.

NAS Download Manager for Synology is an independent, open-source browser extension. It is not produced, endorsed, or supported by Synology Inc. Synology and Download Station are trademarks of their respective owner.

## Short disclosure for the listing

The extension communicates directly with the Synology NAS address configured by the user. It does not use analytics, advertising, or tracking services. See the published privacy policy for details.
